# Course content

One file per course. Each course has 5 modules, each module has 3 lessons and a 2-question quiz.

```
webDevelopment.js          Web Development
uiUxDesign.js              Web Design & UI/UX Design
pythonProgramming.js       Python Programming
javaDsa.js                 Java Programming & DSA
aiMachineLearning.js       AI & Machine Learning
cybersecurity.js           Cybersecurity & Ethical Hacking
appDevelopment.js          App Development
cloudDevops.js             Cloud Computing & DevOps
videoEditing.js            Video Editing
digitalMarketingSeo.js     Digital Marketing & SEO
helpers.js                 L / Q / M / R helpers
index.js                   Registers all courses, adds banners and lesson ids
search.js                  Search used by the search box
```

Search keywords for a course are in its `tags` array (add Hinglish words people may type).
